# Smart Backup Utility

A Python-based backup automation utility designed to create reliable and efficient backups of files and directories.

## Features

- Incremental backup support
- File change detection
- Duplicate handling
- Preview mode with confirmation
- Backup verification
- Ignore rules
- Logging and backup reports
- Command-line arguments for source and backup paths
- Multiple project versions from v3.1 to v3.6
- Docker support

## Project Structure

- `v3.1/` — Initial version
- `v3.2/` — Improved backup functionality
- `v3.3/` — Further improvements
- `v3.4/` — Extended functionality
- `v3.5/` — Improved backup workflow
- `v3.6/` — Latest version
- `dockerfile` — Docker configuration
- `.dockerignore` — Docker build exclusions
